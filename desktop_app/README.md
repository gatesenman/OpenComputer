# OpenComputer 桌面端

一个面向新手的图形化桌面应用，让你无需命令行即可使用 OpenComputer 框架。

## 功能

- **首页概览** — 查看项目状态（任务数、应用数、验证器数、评估运行数）
- **设置配置** — 通过图形界面配置 API 密钥、运行后端、评估参数
- **运行评估** — 选择应用、模型、参数，一键启动评估，实时查看日志
- **任务浏览** — 浏览和搜索所有评估任务，查看详细信息
- **评估结果** — 查看历史评估结果，包括得分、轨迹、截图

## 安装

### 前置要求

- Python 3.9+
- pip

### 快速安装

```bash
# 安装桌面端依赖
pip install PyQt5>=5.15

# 安装项目依赖
pip install -r requirements.txt
```

## 启动

### 方法一：双击启动

- **Windows**: 双击 `launch_desktop.bat`
- **Linux/macOS**: 双击或运行 `./launch_desktop.sh`

### 方法二：命令行启动

```bash
python launch_desktop.py
# 或
python desktop_app/main.py
```

## 使用流程

1. **配置 API 密钥** — 在「设置」页面填入至少一个模型的 API 密钥
2. **选择后端** — E2B（推荐，云沙盒）或 Docker（本地运行）
3. **浏览任务** — 在「任务浏览」页面查看可用的评估任务
4. **运行评估** — 在「运行评估」页面选择应用、模型和参数后开始
5. **查看结果** — 在「评估结果」页面查看运行记录
