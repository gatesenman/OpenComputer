端到端使用流程

按照左侧导航栏从上到下的顺序，即可走完整个评估流程。

1环境安装 — 安装依赖、创建配置、构建沙盒
2设置 — API 密钥、运行后端、Docker、评估参数
3验证器管理 — 查看 33 个应用验证器的代码和文档
4Smoke 测试 — 在真实沙盒中验证验证器端点
5任务生成 — 查看流水线产物（提案→评估→最终任务）
6任务浏览 — 搜索/筛选 900+ 评估任务
7运行评估 — 选择应用/模型/参数，一键启动
8重新评估 — 用不同模型重跑，对比表现
9评估结果 — 查看得分/轨迹/截图，导出报告
10-12修复 · 沙盒 · 清理 — 可选调试维护工具
